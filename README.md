  <h1 align="center"> $${\color{red}AgoraLink}$$  </h1>

A community oriented information software to focus on informing the public of events and encouraging connection. Based on 
inspiration from similar technology in my travels to Japan. This software serves as a public information board that can updated via a Firebase console. It is based in dart/java21 and is based on The Flutter Framework!

Other platforms need to be compiled in flutter by using the flutter build command. Additional documentation can be found on flutter's website. Right now: Web, Android, and Linux builds are functional and interoperable. They both update with relevant information at the same time!
